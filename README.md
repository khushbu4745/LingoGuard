# 📚 LingoGuard — AI Learning Companion

> An AI-powered conversational learning assistant that integrates Large Language Models (LLMs) with speech processing to deliver personalized learning, dynamic lesson generation, and real-time pronunciation feedback.


## 🚀 Overview

**LingoGuard** enhances language learning through interactive AI conversations and speech-based evaluation. It combines state-of-the-art LLM capabilities with audio processing to provide real-time pronunciation scoring, adaptive lesson generation, and personalized feedback — all in a seamless, conversational interface.

---

## ✨ Features

### 💬 Conversational AI
- Context-aware interactions powered by GPT-4
- Personalized responses based on individual user history
- Maintains conversational continuity across sessions

### 📖 Dynamic Lesson Generation
- Lessons generated dynamically based on user activity and progress
- Adaptive difficulty, vocabulary, and topic selection
- Supports structured, progressive learning paths

### 🎙️ Pronunciation Evaluation
- Captures live speech input via the browser
- Evaluates pronunciation using MFCC feature extraction and DTW comparison
- Delivers natural language feedback generated by the LLM

### 🧠 Prompt Engineering
- Optimized prompts for accurate, context-relevant responses
- Engineered for enhanced engagement and learning effectiveness

## 🔊 Pronunciation Evaluation Pipeline

```
1. Data Preparation
   └── Collected & cleaned reference audio; standardized sampling rates

2. User Input Processing
   └── Browser captures audio → normalization & noise trimming

3. Feature Extraction
   └── MFCC extraction via Librosa

4. Audio Comparison
   └── User vs. reference audio using Dynamic Time Warping (DTW)

5. Scoring System
   └── Similarity → accuracy score → performance level classification

6. Feedback Generation
   └── Evaluation results passed to GPT-4 → natural language feedback
```

## 🛠️ Installation & Setup

### Prerequisites

- Python 3.9+
- Node.js 18+
- OpenAI API Key

### 1. Clone the Repository

```bash
git clone https://github.com/khushbu4745/LingoGuard.git
cd LingoGuard
```

### 2. Backend Setup

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

> The API will be available at `http://localhost:8000`

### 3. Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

> The app will be available at `http://localhost:3000`

### 4. Environment Variables

Create a `.env` file in the `backend/` directory:

```env
OPENAI_API_KEY=your_openai_api_key_here
```
